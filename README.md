# Meu Primeiro Projeto 

Este foi meu primeiro projeto em programação, desenvolvido utilizando o Visual Studio Code.

Criei um contador interativo com JavaScript, aplicando conceitos básicos de desenvolvimento web.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- Visual Studio Code

## Funcionalidades
- Aumentar número
- Diminuir número
- Zerar contador
- Limite máximo de valor
- Mudança de cor ao se aproximar do limite

## Objetivo
Praticar lógica de programação, manipulação do DOM e interação com o usuário.
